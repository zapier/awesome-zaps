# Create monthly investor update and assign drafting task

Each month, a dated investor update is created from your template, a drafting task links to it, and your collaborators get the link so the report is ready to review.

**Apps:** Schedule by Zapier, Google Docs, ClickUp, Email by Zapier

**Based on:** [Create monthly investor update and assign drafting task](https://zapier.com/automations/executives/investor-board-reporting/investor-update-distribution/create-monthly-investor-update-and-assign-drafting-task) on zapier.com

## Install

This folder is a Zap template. Paste this into your AI agent:

> Build me this Zap, read how here: https://github.com/zapier/awesome-zaps/tree/main/zaps/create-monthly-investor-update-and-assign-drafting-task

The agent follows `SKILL.md`: it asks you for your template document, output folder, ClickUp workspace and drafting owner, and who gets the ready email, then builds, tests and turns on the Zap in your account.

## Files

- `SKILL.md`: what the agent asks, builds and tests
- `workflow.ts`: the Zap's code
- `config.ts`: its settings; the `REPLACE_…` values are filled in for each person
- `connections/`: the accounts it uses (`clickup`, `google-docs`)
- `triggers/`: what starts it
