# Apply splits on copyright change for song entries

When a song's copyright allocation changes in your monday.com board, the split percentages for each co-writer are recalculated and written back to the item.

**Apps:** monday.com

**Based on:** [Apply splits on copyright change for song entries](https://zapier.com/automations/legal/intellectual-property-management/copyright-management/apply-splits-on-copyright-change-for-song-entries) on zapier.com

## Install

This folder is a Zap template. Paste this into your AI agent:

> Build me this Zap, read how here: https://github.com/zapier/awesome-zaps/tree/main/zaps/apply-splits-on-copyright-change-for-song-entries

The agent follows `SKILL.md`: it asks you which board holds the song entries and which columns hold the allocation and splits, then builds, tests and turns on the Zap in your account.

## Files

- `SKILL.md`: what the agent asks, builds and tests
- `workflow.ts`: the Zap's code
- `config.ts`: its settings; the `REPLACE_…` values are filled in for each person
- `connections/`: the account it uses (`monday`)
- `triggers/`: what starts it
