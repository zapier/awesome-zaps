# Create termination letter and save to client folder

When a termination request comes in, a termination letter is filled in from your template and saved to the client's folder, ready for review.

**Apps:** Webhooks by Zapier, Google Docs

**Based on:** [Create termination letter and save to client folder](https://zapier.com/automations/legal/legal-document-automation/legal-letter-generation/create-termination-letter-and-save-to-client-folder) on zapier.com

## Install

This folder is a Zap template. Paste this into your AI agent:

> Build me this Zap, read how here: https://github.com/zapier/awesome-zaps/tree/main/zaps/create-termination-letter-and-save-to-client-folder

The agent follows `SKILL.md`: it asks you for your termination letter template, then builds, tests and turns on the Zap in your account.

## Files

- `SKILL.md`: what the agent asks, builds and tests
- `workflow.ts`: the Zap's code
- `config.ts`: its settings; the `REPLACE_…` values are filled in for each person
- `connections/`: the account it uses (`google-docs`)
- `triggers/`: what starts it
