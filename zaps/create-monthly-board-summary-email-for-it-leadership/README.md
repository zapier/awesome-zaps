# Create monthly board summary email for IT leadership

Once a month, the open cards on your Trello board are listed in one email to leadership, with each card's status, last activity and link.

**Apps:** Schedule by Zapier, Trello, Gmail

**Based on:** [Create monthly board summary email for IT leadership](https://zapier.com/automations/executives/reporting-management/cross-functional-report-aggregation/create-monthly-board-summary-email-for-it-leadership) on zapier.com

## Install

This folder is a Zap template. Paste this into your AI agent:

> Build me this Zap, read how here: https://github.com/zapier/awesome-zaps/tree/main/zaps/create-monthly-board-summary-email-for-it-leadership

The agent follows `SKILL.md`: it asks you for the Trello board to summarize and who gets the summary, then builds, tests and turns on the Zap in your account.

## Files

- `SKILL.md`: what the agent asks, builds and tests
- `workflow.ts`: the Zap's code
- `config.ts`: its settings; the `REPLACE_…` values are filled in for each person
- `connections/`: the accounts it uses (`gmail`, `trello`)
- `triggers/`: what starts it
