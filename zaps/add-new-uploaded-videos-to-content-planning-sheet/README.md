# Add new uploaded videos to content planning sheet

When a video lands in your staging folder, it's added as a row in your content planning sheet, with its name, upload time and link, so the team can schedule and approve it.

**Apps:** Google Drive, Google Sheets

**Based on:** [Add new uploaded videos to content planning sheet](https://zapier.com/automations/marketing/content-marketing/content-calendar-management/add-new-uploaded-videos-to-content-planning-sheet) on zapier.com

## Install

This folder is a Zap template. Paste this into your AI agent:

> Build me this Zap, read how here: https://github.com/zapier/awesome-zaps/tree/main/zaps/add-new-uploaded-videos-to-content-planning-sheet

The agent follows `SKILL.md`: it asks you for the staging folder, the planning sheet and its columns, then builds, tests and turns on the Zap in your account.

## Files

- `SKILL.md`: what the agent asks, builds and tests
- `workflow.ts`: the Zap's code
- `config.ts`: its settings; the `REPLACE_…` values are filled in for each person
- `connections/`: the accounts it uses (`google-drive`, `google-sheets`)
- `triggers/`: what starts it
