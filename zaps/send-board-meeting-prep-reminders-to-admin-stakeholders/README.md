# Send board meeting prep reminders to admin stakeholders

Each month, stakeholders get an email reminding them to submit board packet materials, with the agenda link, so the packet is ready on time.

**Apps:** Schedule by Zapier, Gmail

**Based on:** [Send board meeting prep reminders to admin stakeholders](https://zapier.com/automations/executives/investor-board-reporting/board-meeting-preparation/send-board-meeting-prep-reminders-to-admin-stakeholders) on zapier.com

## Install

This folder is a Zap template. Paste this into your AI agent:

> Build me this Zap, read how here: https://github.com/zapier/awesome-zaps/tree/main/zaps/send-board-meeting-prep-reminders-to-admin-stakeholders

The agent follows `SKILL.md`: it asks you for who receives the reminder, the meeting date and the agenda link, then builds, tests and turns on the Zap in your account.

## Files

- `SKILL.md`: what the agent asks, builds and tests
- `workflow.ts`: the Zap's code
- `config.ts`: its settings; the `REPLACE_…` values are filled in for each person
- `connections/`: the account it uses (`gmail`)
- `triggers/`: what starts it
