# Create probate property valuation report and save to record

When a probate valuation record is ready, a polished report is generated from your template and its link is saved on the record, so case tracking stays current.

**Apps:** Webhooks by Zapier, Zapier Tables, Google Docs

**Based on:** [Create probate property valuation report and save to record](https://zapier.com/automations/legal/legal-document-automation/document-assembly/create-probate-property-valuation-report-and-save-to-record) on zapier.com

## Install

This folder is a Zap template. Paste this into your AI agent:

> Build me this Zap, read how here: https://github.com/zapier/awesome-zaps/tree/main/zaps/create-probate-property-valuation-report-and-save-to-record

The agent follows `SKILL.md`: it asks you for the valuation table, the report template and the report folder, then builds, tests and turns on the Zap in your account.

## Files

- `SKILL.md`: what the agent asks, builds and tests
- `workflow.ts`: the Zap's code
- `config.ts`: its settings; the `REPLACE_…` values are filled in for each person
- `connections/`: the accounts it uses (`zapier-tables`, `google-docs`)
- `triggers/`: what starts it
