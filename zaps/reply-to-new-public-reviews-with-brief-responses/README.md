# Reply to new public reviews with brief responses

Each new Google review gets a short, friendly public reply posted under it, so reviewers hear back without you writing every response.

**Apps:** Google Business Profile

**Based on:** [Reply to new public reviews with brief responses](https://zapier.com/automations/marketing/review-reputation-management/review-response-management/reply-to-new-public-reviews-with-brief-responses) on zapier.com

## Install

This folder is a Zap template. Paste this into your AI agent:

> Build me this Zap, read how here: https://github.com/zapier/awesome-zaps/tree/main/zaps/reply-to-new-public-reviews-with-brief-responses

The agent follows `SKILL.md`: it asks you which Google Business Profile location to watch, then builds, tests and turns on the Zap in your account.

## Files

- `SKILL.md`: what the agent asks, builds and tests
- `workflow.ts`: the Zap's code
- `config.ts`: its settings; the `REPLACE_…` values are filled in for each person
- `connections/`: the account it uses (`google-business-profile`)
- `triggers/`: what starts it
