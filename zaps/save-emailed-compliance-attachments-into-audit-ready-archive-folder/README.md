# Save emailed compliance attachments into audit-ready archive folder

Each attachment emailed to you is saved into your compliance archive folder with a clear, dated file name, so reviewers can find evidence quickly.

**Apps:** Microsoft Outlook, Google Drive

**Based on:** [Save emailed compliance attachments into audit-ready archive folder](https://zapier.com/automations/it/security-compliance/compliance-evidence-collection/save-emailed-compliance-attachments-into-audit-ready-archive-folder) on zapier.com

## Install

This folder is a Zap template. Paste this into your AI agent:

> Build me this Zap, read how here: https://github.com/zapier/awesome-zaps/tree/main/zaps/save-emailed-compliance-attachments-into-audit-ready-archive-folder

The agent follows `SKILL.md`: it asks you for your archive folder and the mailbox to watch, then builds, tests and turns on the Zap in your account.

## Files

- `SKILL.md`: what the agent asks, builds and tests
- `workflow.ts`: the Zap's code
- `config.ts`: its settings; the `REPLACE_…` values are filled in for each person
- `connections/`: the accounts it uses (`google-drive`, `microsoft-outlook`)
- `triggers/`: what starts it
