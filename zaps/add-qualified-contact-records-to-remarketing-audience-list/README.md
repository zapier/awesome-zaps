# Add qualified contact records to remarketing audience list

When a new client row reaches a qualifying case status, that contact is added to your Google Ads remarketing list so you can reach them with timely ads.

**Apps:** Zapier Tables, Google Ads

**Based on:** [Add qualified contact records to remarketing audience list](https://zapier.com/automations/marketing/advertising-ppc/retargeting-audience-management/add-qualified-contact-records-to-remarketing-audience-list) on zapier.com

## Install

This folder is a Zap template. Paste this into your AI agent:

> Build me this Zap, read how here: https://github.com/zapier/awesome-zaps/tree/main/zaps/add-qualified-contact-records-to-remarketing-audience-list

The agent follows `SKILL.md`: it asks you for your contact table, Google Ads account and customer list, then builds, tests and turns on the Zap in your account.

## Files

- `SKILL.md`: what the agent asks, builds and tests
- `workflow.ts`: the Zap's code
- `config.ts`: its settings; the `REPLACE_…` values are filled in for each person
- `connections/`: the accounts it uses (`google-ads`, `zapier-tables`)
- `triggers/`: what starts it
