# Save trademark search report attachments to central folder

Attachments from incoming trademark search report emails are saved into one central Google Drive folder, named by date and subject, so legal can review them in one place.

**Apps:** Gmail, Google Drive

**Based on:** [Save trademark search report attachments to central folder](https://zapier.com/automations/legal/intellectual-property-management/trademark-management/save-trademark-search-report-attachments-to-central-folder) on zapier.com

## Install

This folder is a Zap template. Paste this into your AI agent:

> Build me this Zap, read how here: https://github.com/zapier/awesome-zaps/tree/main/zaps/save-trademark-search-report-attachments-to-central-folder

The agent follows `SKILL.md`: it asks you for the central Google Drive folder, then builds, tests and turns on the Zap in your account.

## Files

- `SKILL.md`: what the agent asks, builds and tests
- `workflow.ts`: the Zap's code
- `config.ts`: its settings; the `REPLACE_…` values are filled in for each person
- `connections/`: the accounts it uses (`gmail`, `google-drive`)
- `triggers/`: what starts it
