# Generate social caption and 1080 image for posts

When a content idea goes into your table, its row gets a caption, hashtags and a square image, and is marked publish-ready for review.

**Apps:** Zapier Tables, AI by Zapier, Google AI Studio (Gemini)

**Based on:** [Generate social caption and 1080 image for posts](https://zapier.com/automations/design/content-media-production/social-media-asset-creation/generate-social-caption-and-1080-image-for-posts) on zapier.com

## Install

This folder is a Zap template. Paste this into your AI agent:

> Build me this Zap, read how here: https://github.com/zapier/awesome-zaps/tree/main/zaps/generate-social-caption-and-1080-image-for-posts

The agent follows `SKILL.md`: it asks you for the content table and its fields, then builds, tests and turns on the Zap in your account.

## Files

- `SKILL.md`: what the agent asks, builds and tests
- `workflow.ts`: the Zap's code
- `config.ts`: its settings; the `REPLACE_…` values are filled in for each person
- `connections/`: the accounts it uses (`ai`, `google-ai-studio`, `zapier-tables`)
- `triggers/`: what starts it
