# Create standardized resized image copies in your media folder

Each hour, new images in your source folder get a size-named copy in your media folder, so content teams find standardized files without renaming anything.

**Apps:** Schedule by Zapier, Google Drive

**Based on:** [Create standardized resized image copies in your media folder](https://zapier.com/automations/design/content-media-production/image-resizing-formatting/create-standardized-resized-image-copies-in-your-media-folder) on zapier.com

## Install

This folder is a Zap template. Paste this into your AI agent:

> Build me this Zap, read how here: https://github.com/zapier/awesome-zaps/tree/main/zaps/create-standardized-resized-image-copies-in-your-media-folder

The agent follows `SKILL.md`: it asks you for your source and media folders in Google Drive, then builds, tests and turns on the Zap in your account.

## Files

- `SKILL.md`: what the agent asks, builds and tests
- `workflow.ts`: the Zap's code
- `config.ts`: its settings; the `REPLACE_…` values are filled in for each person
- `connections/`: the account it uses (`google-drive`)
- `triggers/`: what starts it
