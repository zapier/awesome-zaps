# Create IT ticket for updated website asset record

When a website asset record changes, an IT ticket is created for it with the asset's details, so engineers can act right away.

**Apps:** Airtable

**Based on:** [Create IT ticket for updated website asset record](https://zapier.com/automations/it/it-service-management/it-ticketing/create-it-ticket-for-updated-website-asset-record) on zapier.com

## Install

This folder is a Zap template. Paste this into your AI agent:

> Build me this Zap, read how here: https://github.com/zapier/awesome-zaps/tree/main/zaps/create-it-ticket-for-updated-website-asset-record

The agent follows `SKILL.md`: it asks you for your Airtable base and tables and the column names it should use, then builds, tests and turns on the Zap in your account.

## Files

- `SKILL.md`: what the agent asks, builds and tests
- `workflow.ts`: the Zap's code
- `config.ts`: its settings; the `REPLACE_…` values are filled in for each person
- `connections/`: the account it uses (`airtable`)
- `triggers/`: what starts it
