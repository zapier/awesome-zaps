# Update deal opt-in status from incoming webhook payloads

When a consent signal arrives on a webhook, this sets the matching Pipedrive deal's consent field to opt-in or opt-out, so sales sees current consent on the deal.

To build it, give your AI agent this prompt:

> Build me this Next Gen Zap using Zapier MCP: https://zapier.sh/zapier/community-skills/update-deal-opt-in-status-from-incoming-webhook-payloads/

Your agent will load the Zapier build skill and walk you through the setup. You will need a Pipedrive connection and the payload key names your consent system sends.
